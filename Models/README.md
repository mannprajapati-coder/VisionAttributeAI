# AI Models Directory

Place your ONNX model weights in their respective folders:
- `models/yolo/`: Place `yolov8n.onnx` (or your chosen YOLO ONNX model).
- `models/par/`: Place `par_model.onnx` (for Pedestrian Attribute Recognition).

These paths can be configured in `appsettings.json` under `VisionAi:Yolo:ModelPath` and `VisionAi:Par:ModelPath`.
